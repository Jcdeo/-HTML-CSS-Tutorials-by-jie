HTML Tutorials

HTML (HyperText Markup Language) is the skeleton of every web page. Learn the essential tags and structure that every web developer must know.

Lesson 1

Basic HTML Document Structure

Every HTML page starts with the same boilerplate. <!DOCTYPE html> tells the browser which version of HTML to use. <html>, <head>, and <body> are the three essential root elements.

Headings & Paragraphs

HTML has six heading levels <h1>–<h6>. <h1> is the most important (used once per page). <p> creates paragraphs. Use <strong> for bold and <em> for italic text.

Text Formatting Tags

HTML provides many inline tags to format text: <b>, <i>, <small>, <sub>, <sup>, <code>, <blockquote>, <br>, and <hr>.

Links & Anchors

The <a> tag creates hyperlinks. href sets the destination. Use target="_blank" to open in a new tab. Links can also jump to sections on the same page using #id.

Images

<img> is a self-closing tag. The src attribute sets the image source and alt provides accessible text. Always include alt for accessibility and SEO.

Lists — Ordered, Unordered & Definition

<ul> makes bullet lists, <ol> makes numbered lists, and <dl> makes definition lists. Lists can be nested inside each other.

Tables

Tables organise data into rows (<tr>) and columns (<td>). Use <th> for header cells, <thead>/<tbody>/<tfoot> for structure, and colspan/rowspan to merge cells.

Forms & Input Elements

Forms collect user input. Key attributes: action (where data is sent), method (GET/POST). Input types include text, email, password, number, date, radio, checkbox, file, and more.

Div, Span, Classes & IDs

<div> is a block-level container; <span> is an inline container. Classes (class="") can be reused on many elements. IDs (id="") must be unique per page and are used for specific targeting.

Selectors target HTML elements. Learn the essential types: element, class (.name), ID (#name), attribute, descendant, child (>), sibling (+, ~), and the universal selector (*).
